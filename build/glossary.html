Renderings I'd flag for a second look

None of these are "wrong" outright — the reasoning behind each is sound — but each has a real risk worth Faisal's eyes before lock:

  • Lotte = لوتّه. The Arabic spelling ends in ة, which visually reads as a feminine name to any Arabic speaker (like Fatima or Ruqayya), even though Lotte is explicitly male and the project rule is to keep masculine agreement throughout. Faisal confirmed keeping this spelling (2026-09-02) rather than respelling — flagging that every Lotte dialogue row still deserves extra QA attention for accidental feminine agreement.
  • Lore Scrolls = لفائف المعرفة. "Lore" here is rendered as "knowledge" (المعرفة), which is accurate but a bit academic — it loses the "legend/myth" flavor "Lore" usually carries in English game UI. Faisal confirmed keeping this rendering (2026-09-02); noting it here in case the academic register reads oddly once seen in full sentences during QA.
  • Stamina — resolved. Was five words (القدرة على التحمل) with real HUD-overflow risk; Faisal shortened it to التحمّل on 2026-09-02, which also resolved a second issue — it now reads distinct from the new Endurance stat (الجَلَد).

Rules that generated the transliterations

From 06_arabic_style_guide.md ("Names and terms") and its base (arabic-localization skill, Ch9), applied consistently across every transliterated name in the glossary:

  • Hard G → ق. English "hard G" (as in "go," not "giant") is rendered ق, never ج or غ. Examples: Gallant → قالانت, Gildenarch → قيلدنارك, Caragus → كاراقوس, Grimhaven → قريمهاڤن, Gajov → قاجوف, Egregore → إيقريقور.
  • V → ڤ. Arabic has no native "v" sound; the glossary uses ڤ (three-dot fa) consistently rather than ف (f) or ب (b). Examples: Velchoria → ڤلتشوريا, Treveyan → تريڤيان, Irvine → إرڤين, Valahk-Nor → ڤالاك-نور, Grimhaven → قريمهاڤن.
  • One frozen spelling per name. Where the English source itself drifts (typos, inconsistent hyphenation, renamed keys), the glossary locks a single Arabic spelling rather than reproducing the drift: Felwyl is one spelling despite source variants "Fewyl"/"Felwil"; Valahk-Nor's hyphen is normalized despite "Valahk – Nor"/"Valahk Nor"/"General Valahk"; Luderaeon is used over the older "Ludereon" key; Akyreon is used over the older "Iridaeon" key.
  • Minimal hamza use. Where the base style guide favors readability over phonetic exactness, medial glide letters (ي/و) are preferred over stacking hamza-seats for vowel clusters — e.g. Aegoroth → إيقوروث and Maedrael → مايدرايل use ي rather than chaining multiple hamzas, keeping the transliterations easy to read aloud rather than technically precise.

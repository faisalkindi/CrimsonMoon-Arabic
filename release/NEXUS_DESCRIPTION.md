# Crimson Moon — Arabic Localization / التعريب الكامل

## العربية

**تعريب عربي كامل للعبة Crimson Moon** — ترجمة جديدة من الصفر لكل نصوص اللعبة (أكثر من 8,600 سطر): القوائم، الحوارات، أوصاف الأسلحة والدروع والبركات، المهام، رسائل التعليم، ملاحظات القصة، وترجمة المشاهد السينمائية (المقدمة والخاتمة).

**المميزات**
- تُضاف العربية كلغة داخل إعدادات اللعبة (تظهر باسم «Arabic») — لا تستبدل أي لغة أخرى.
- خط عربي واضح مدمج داخل خطوط اللعبة الأصلية (Asul وCrimson Text وRoboto)، فتبقى الحروف اللاتينية كما هي.
- واجهة معكوسة من اليمين إلى اليسار في القوائم وشريط التبويبات وخريطة أزرار التحكم.
- مصطلحات موحّدة عبر اللعبة كلها (مسرد يضم 190+ مصطلحًا مُقرًّا يدويًا)، مراجعة تحريرية مستقلة، ثم مراجعة دلالية مزدوجة لكل سطر.
- لا يعدّل أي ملف أصلي من ملفات اللعبة.

**التثبيت**
1. أغلق اللعبة.
2. شغّل `Crimson Moon Arabic Installer.exe` — يكتشف مجلد اللعبة تلقائيًا من Steam (أو حدّده يدويًا).
3. اضغط «تثبيت اللغة العربية».
4. داخل اللعبة: الإعدادات ← إمكانية الوصول ← تغيير اللغة ← «Arabic» ← تطبيق، ثم أعد تشغيل اللعبة.

**الإزالة**: نفس المثبّت ← «إزالة اللغة العربية». يحذف ملفات التعريب الخمسة فقط.

**التثبيت اليدوي**
- انسخ `zzz_Arabic_P.pak` و`zzz_Arabic_P.ucas` و`zzz_Arabic_P.utoc` إلى `<مجلد اللعبة>\CrimsonMoonNG\Content\Paks\`
- انسخ `Intro_ar.srt` و`CINE_EndGame_ar.srt` إلى `<مجلد اللعبة>\CrimsonMoonNG\Content\Movies\`

**ملاحظات**
- الإصدار: 0.2 (Steam). بعض النصوص القصيرة في الواجهة قد تحتاج ضبطًا في الإصدارات القادمة.
- الخط العربي: SST Arabic (Samsung) — للاستخدام غير التجاري.

## English

**Complete Arabic localization for Crimson Moon** — a from-scratch translation of every line in the game (8,600+ strings): menus, dialogue, weapon/armor/boon descriptions, quests, tutorials, lore notes, plus the intro and ending cinematic subtitles.

**Features**
- Arabic is added as a language in the in-game settings (listed as «Arabic») — no other language is replaced.
- Arabic glyphs merged into the game's own fonts (Asul, Crimson Text, Roboto), so Latin text keeps its original design.
- Right-to-left layout in menus, tab bars and the controller map.
- Consistent terminology across the whole game (190+ hand-approved glossary terms), an independent editorial pass, and a dual-model semantic review of every line.
- No original game file is modified.

**Install**
1. Close the game.
2. Run `Crimson Moon Arabic Installer.exe` — it auto-detects the Steam install (or pick the folder manually).
3. Click the install button.
4. In game: Settings → Accessibility → Change Language → «Arabic» → Apply, then restart the game.

**Uninstall**: same installer → the uninstall button. Removes only the five mod files.

**Manual install**
- Copy `zzz_Arabic_P.pak`, `zzz_Arabic_P.ucas`, `zzz_Arabic_P.utoc` into `<game folder>\CrimsonMoonNG\Content\Paks\`
- Copy `Intro_ar.srt`, `CINE_EndGame_ar.srt` into `<game folder>\CrimsonMoonNG\Content\Movies\`

**Notes**
- Version 0.2, Steam build 1.0.0.160034. Some short UI labels may still be tuned in later releases.
- Font: SST Arabic (Samsung), non-commercial use.
- Compatibility: other mods that replace the same fonts or the `ar` locres will conflict.
